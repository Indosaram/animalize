# Animalize 크롬 확장

웹페이지에서 타자를 칠 때마다 치이카와, 하치와레, 우사기, 모몽가, 시사, 쿠리만쥬 같은 캐릭터 목소리가 나와요. 프로그램을 설치하지 않고 크롬에서만 쓰고 싶을 때 쓰세요.

## 설치하기

1. [animalize-chrome-extension.zip](https://github.com/Indosaram/animalize/releases/latest/download/animalize-chrome-extension.zip)을 받아요.
2. 받은 zip 파일을 두 번 눌러 폴더로 풀어요.
3. 크롬 주소창에 `chrome://extensions` 를 입력하고 엔터를 눌러요.
4. 오른쪽 위의 **개발자 모드** 스위치를 켜요.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 2번에서 푼 폴더를 골라요.
6. 주소창 오른쪽 퍼즐 모양을 누르고 Animalize 옆 핀을 누르면 아이콘이 늘 보여요.

## 쓰는 법

- 확장 아이콘을 누르면 캐릭터를 고를 수 있어요. 카드를 누르면 바로 한 번 들려줘요.
- 아무 웹페이지에서나 타자를 치면 고른 캐릭터 목소리가 나와요.
- 비밀번호 칸에서는 소리가 나지 않아요.
- 맨 위 스위치를 끄면 바로 조용해져요.

## 내 소리로 바꾸기

캐릭터마다 진짜 소리가 12개씩 들어 있어요. 다른 소리로 바꾸고 싶다면:

1. 확장 아이콘을 누르고 캐릭터 카드를 골라요.
2. **캐릭터 진짜 소리 넣기** 칸에서 마음에 안 드는 소리를 **지우기**로 지워요.
3. 같은 칸에 짧은 소리 파일(mp3, wav, m4a / 파일당 1MB 이하)을 끌어다 놓아요. 캐릭터마다 12개까지 넣을 수 있어요.

넣은 소리는 이 크롬에만 저장되고 어디에도 올라가지 않아요.
