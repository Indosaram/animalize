# Animalize 크롬 확장 설치하기

웹페이지에서 타자를 치면 치이카와 느낌, 하치와레 느낌 같은 귀여운 목소리가 나오는 확장 프로그램이에요.

## 설치 순서

1. 이 저장소에서 `bun install` 후 `bun run build:ext` 를 실행해요. `extension/dist` 폴더가 만들어져요.
2. 크롬 주소창에 `chrome://extensions` 를 입력해요.
3. 오른쪽 위의 **개발자 모드** 스위치를 켜요.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 눌러요.
5. `extension/dist` 폴더를 골라요.
6. 주소창 옆 퍼즐 모양 아이콘을 눌러 Animalize를 고정하면 편해요.

## 쓰는 법

- 확장 아이콘을 누르면 목소리를 고를 수 있어요. 카드를 누르면 바로 미리 들려줘요.
- 아무 웹페이지에서나 타자를 치면 고른 목소리가 나와요.
- 비밀번호 칸에서는 소리가 나지 않아요.
- 맨 위 스위치로 언제든 소리를 끌 수 있어요.
- "내 목소리 만들기"에서 높낮이와 빠르기를 바꾸거나, 내 소리 파일(mp3, wav, m4a / 2MB 이하)을 올려 쓸 수 있어요.

## 캐릭터 진짜 소리 넣기

치이카와의 "하앗", "와아" 같은 짧은 진짜 소리를 직접 넣으면, 타자를 칠 때 그 소리가 하나씩 골고루 나와요.

1. 확장 아이콘을 누르고 소리를 넣을 캐릭터 카드를 골라요.
2. 바로 아래 **캐릭터 진짜 소리 넣기** 칸에 소리 파일을 끌어다 놓거나, 눌러서 골라요. (mp3, wav, m4a / 파일당 1MB 이하 / 캐릭터마다 12개까지)
3. 목록에서 **미리 듣기**로 들어 보고, 필요 없는 소리는 **지우기**로 지워요.
4. 소리를 넣은 캐릭터 카드에는 "진짜 소리 N개" 표시가 붙어요.

- 소리 파일은 직접 준비해야 해요. 이 프로그램에는 캐릭터의 실제 소리가 들어 있지 않아요.
- 넣은 소리는 내 컴퓨터(크롬 확장 저장소)에만 저장되고 어디에도 올라가지 않아요.
- 저작권이 있는 소리를 다른 사람에게 나눠 주거나 퍼뜨리면 안 돼요. 개인적으로 즐기는 용도로만 써 주세요.

캐릭터 목소리는 분위기를 흉내 낸 합성 효과이며 공식 음성이 아닙니다.
